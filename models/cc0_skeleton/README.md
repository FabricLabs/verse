# CC0 humanoid skeletons

Third-party CC0 humanoid skeletons staged for procedural bone/flesh voxelisation
(`scripts/skeleton_voxel_flesh.py`) and animation baking.

| Path | Source | License | Notes |
|------|--------|---------|-------|
| `kenney_animated_characters_3/` | [Kenney Animated Characters 3](https://opengameart.org/content/animated-characters-3) | CC0 | Primary: medium humanoid + Idle/Run/Jump |
| `quaternius_ual/` | [Quaternius Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html) | CC0 | Retarget-friendly humanoid animation kit (glTF) |
| `gobkit_minion_a01.glb` | [Gobkit Free Minions](https://gobkit.itch.io/gobkit-free-minions) | CC0 | Compact rigged minion reference |

The Flesh Walker mob is generated from the Kenney pack.
